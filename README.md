# Sweet Mandy — Next.js + PWA

Professional ordering web app for **Sweet Mandy Bakery's** (Ijegun, Lagos).

## Design
- **Same professional structure** as the earlier Sweet Mandy build (from Ziva base)
- **Warm orange primary** colour system (not Lovable cocoa theme)
- **Images** from Lovable project only (hero + category photos + food shots)

## Features
- Menu, cart, Take Away & Delivery (Mainland)
- Customer / Admin / Rider dashboards
- **Real PWA**: manifest + service worker + install icons
- Mock data (no backend required to preview)

## Run
```bash
npm install
npm run dev
```
http://localhost:3000

## PWA install
Use HTTPS or localhost → browser menu → Install app / Add to Home Screen.
